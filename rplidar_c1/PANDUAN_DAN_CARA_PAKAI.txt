1. TENTANG SLAMTEC RPLIDAR C1
--------------------------------------------------------------------------------
Slamtec RPLIDAR C1 adalah sensor LiDAR 2D 360 derajat berbasis teknologi DTOF
(Direct Time-of-Flight) dengan jangkauan 0.05 m s/d 12 meter dan frekuensi sampling
hingga 5.000 Hz.

CATATAN PENTING:
- Baud rate default untuk RPLIDAR C1 adalah 460800 bps (berbeda dengan tipe A1/A2
  lama yang menggunakan 115200 bps).
- Jika baud rate salah, sensor tidak akan mengirimkan data atau motor pemindai
  tidak akan berputar. Kode ini sudah otomatis dikonfigurasi pada 460800 bps.

--------------------------------------------------------------------------------
3. KONFIGURASI HAK AKSES PORT SERIAL (PENTING DI LINUX)
--------------------------------------------------------------------------------
Di sistem Linux (seperti Ubuntu), port serial (/dev/ttyUSB0 atau /dev/ttyACM0)
secara default hanya dapat diakses oleh user dalam grup 'dialout'.

Jika muncul pesan error "Permission denied: '/dev/ttyUSB0'":
1. Tambahkan user Anda ke grup dialout:
      sudo usermod -a -G dialout $USER

2. Atau berikan izin akses langsung ke port:
      sudo chmod 666 /dev/ttyUSB0

3. Catatan: Setelah menjalankan usermod, lakukan logout dan login kembali agar
   grup dialout aktif.

6. KONTROL TOMBOL PADA TAMPILAN RADAR (KEYBOARD SHORTCUTS)
--------------------------------------------------------------------------------
Saat jendela radar terbuka, Anda dapat mengontrol tampilan dengan tombol berikut:

[ + ] atau [ = ] : ZOOM IN (mempersempit jarak jangkauan radar, misal 2m, 3m)
[ - ] atau [ _ ] : ZOOM OUT (memperluas jarak jangkauan radar hingga 16 meter)
[ SPASI ]        : PAUSE / RESUME (membekukan pemindaian untuk inspeksi objek)
[ S ]            : SCREENSHOT (menyimpan gambar radar saat ini ke file PNG,
                   contoh: lidar_scan_20261013_193000.png)
[ Q ] atau [ESC] : KELUAR (menghentikan pemindaian, mematikan motor/laser
                   dengan aman, lalu menutup aplikasi)


--------------------------------------------------------------------------------
7. FITUR YANG TERSEDIA PADA TAMPILAN RADAR
--------------------------------------------------------------------------------
1. Lingkaran Jarak (Distance Rings):
   Garis konsentris menunjukkan jarak dalam meter (1m, 2m, 3m, dst).
2. Sumbu Arah & Sudut:
   - 0°   : Arah depan (Front) sensor
   - 90°  : Arah kanan (Right) sensor
   - 180° : Arah belakang (Back) sensor
   - 270° : Arah kiri (Left) sensor
3. Pewarnaan Titik (Color Gradient):
   - Warna Merah/Oranye : Objek berjarak sangat dekat (< 1.5 m)
   - Warna Kuning/Hijau : Objek berjarak menengah (1.5 m - 4 m)
   - Warna Cyan/Biru    : Objek berjarak jauh (> 4 m)
4. Pelacak Halangan Terdekat (Closest Obstacle Tracker):
   Sistem otomatis mendeteksi objek terdekat, menandainya dengan cincin target
   merah, dan menampilkan informasi jarak (cm / m) serta sudutnya secara live.
5. Heads-Up Display (HUD):
   Menampilkan nama perangkat, port serial, baudrate, FPS visualisasi, serta
   laju perolehan titik (points/second).


--------------------------------------------------------------------------------
8. TROUBLESHOOTING (PEMECAHAN MASALAH)
--------------------------------------------------------------------------------
1. Motor LiDAR tidak berputar saat program dijalankan:
   - Pastikan kabel USB terpasang kuat. RPLIDAR C1 membutuhkan arus 5V (sekitar
     1A - 1.5A pada saat startup motor). Jika dicolokkan via USB hub pasif,
     pindahkan langsung ke port USB motherboard/laptop.
   - Periksa apakah port benar dengan mengetik di terminal:
       ls -l /dev/ttyUSB*

2. Muncul error "Permission Denied":
   - Jalankan: sudo chmod 666 /dev/ttyUSB0
   - Dan masukkan akun ke grup dialout: sudo usermod -a -G dialout $USER

3. Layar GUI tidak muncul:
   - Pastikan Anda menjalankan program di lingkungan desktop grafis (bukan SSH
     tanpa X11 forwarding). Variabel DISPLAY harus aktif.

4. Data titik terlihat berputar terbalik:
   - Jika Anda memasang sensor secara terbalik (mounting terbalik pada robot),
     Anda dapat mengubah arah tanda sudut rad di visualizer.py.
